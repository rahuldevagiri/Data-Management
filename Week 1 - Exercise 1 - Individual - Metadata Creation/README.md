# Week 1 - Exercise 1: Dataset Metadata

This repository contains work completed for the **Data Management** course as part of **Week 1 - Exercise 1: Dataset Metadata**.

The task was to use a publicly available dataset and create:
- DataCite metadata in XML format
- schema.org metadata in JSON-LD format using `@type: Dataset`

## Dataset Used

**Dataset title:** Similarity and specialization of the larval versus adult diet of European butterflies and moths  
**Repository:** Dryad  
**Project website:** https://datadryad.org/dataset/doi:10.5061/dryad.cb6pk  
**Dataset DOI:** 10.5061/dryad.cb6pk  
**Related publication DOI:** 10.1086/661248  
**UCI listing:** Not available. This dataset is hosted on Dryad, not the UCI Machine Learning Repository.

## Description

This dataset contains information related to larval host plants and adult nectar sources for Lepidoptera families. The attached file used in this exercise is `Dryad_Family_data.xlsx`, which includes summary values for plant species used as larval food plants and nectaring plants across different Lepidoptera families.

## Files Included

- `dryad_family_data_datacite.xml`
- `dryad_family_data_schemaorg.jsonld`
- `README.md`

## Metadata Outputs

### DataCite XML
This file contains the DataCite metadata record for the dataset in XML format.

### schema.org JSON-LD
This file contains the schema.org metadata record for the dataset using `@type: Dataset`.
